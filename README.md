# Candy Art - Arte que se saborea

Sitio web oficial para la marca de repostería artesanal **Candy Art**, desarrollado como proyecto académico.

## Características
- **Catálogo interactivo:** Selección de pasteles con precios actualizados.
- **Recomendador con IA:** Asistente integrado en JavaScript.
- **Formulario de contacto:** Conectado a correo electrónico mediante Formspree.
- **Consumo de API:** Carga de frases dinámicas desde servicio externo (`dummyjson.com`).
- **Estilos personalizados:** Tipografía artesanal (Pacifico) e interfaz adaptativa.

## Tecnologías
- HTML5
- CSS3
- JavaScript (ES6+ / Fetch API)
- Git & GitHub Pages
